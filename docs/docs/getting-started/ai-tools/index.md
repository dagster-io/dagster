Dagster maintains several AI tools that give coding agents better context and patterns for building Dagster projects. These tools are bundled together in the [`dagster` plugin](/getting-started/ai-tools/plugin) and include:

- [`dagster-expert` skill](/getting-started/ai-tools/skills): The `dagster-expert` skill provides expert guidance for building production-quality Dagster projects, covering [`dg`](/api/clis/cli) CLI usage, asset patterns, automation strategies, and implementation workflows.

- [Dagster+ MCP server](/getting-started/ai-tools/dagster-mcp): The Dagster+ MCP allows you to access information and take actions in your Dagster+ deployment.
